# 📊 App Imposto de Renda

Um modelo de organização e automação em Excel para facilitar a coleta, documentação e consolidação de dados para a Declaração do Imposto de Renda Pessoa Física (IRPF).

## 🎯 Objetivo do Projeto
Fornecer uma estrutura padronizada para que os usuários possam registrar suas informações pessoais, bancárias e notas fiscais/extratos em um único local, agilizando o envio de dados para o contador ou para o próprio sistema da Receita Federal.

## 🗂️ Estrutura da Planilha
A ferramenta é dividida nas seguintes abas:
- **Titular:** Coleta de dados básicos (Nome, CPF, Data de Nascimento, Título de Eleitor, Endereço e Cônjuge).
- **Informes:** Registro de rendimentos bancários com associação de documentos anexos (PDFs).
- **Notas:** Controle de entradas e saídas de extratos ou holerites categorizados por data.
- **Tabela:** Base de dados relacionais contendo os códigos oficiais de compensação dos bancos brasileiros.

## 🚀 Como Utilizar
1. Faça o clone do repositório ou o download do arquivo `App_Imposto_renda.xlsx`.
2. Preencha a aba **Titular** com as suas informações pessoais.
3. Na aba **Informes**, insira o saldo de cada instituição e vincule o arquivo PDF do informe correspondente.
4. Utilize a aba **Notas** para documentar movimentações financeiras importantes que exijam comprovação de categoria.

## 🛠️ Tecnologias Utilizadas
* Microsoft Excel / Validação de Dados / Estruturação em Tabelas.
